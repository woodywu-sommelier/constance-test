# The Constance Test

The Constance Test evaluates wine AI answers for fabricated facts, false premises, unsupported scores, provenance mistakes and invented sensory experience. Version 0.2 has 51 public development questions. The private test questions are not in this repository.

- Run the [one-minute example](../README.md#try-it-in-one-minute) with Python 3.11 or later. The local scorer has no network calls or telemetry. Use your own model runner to produce new answers.
- Machine patterns are a first pass, not a final judge. Unclear replies need review. The table tier is scored separately by a person.
- The [public v0.2 baseline](https://woodywusommelier.com/constance-test/?utm_source=github&utm_medium=readme&utm_content=constance-test-llms-results) does not measure performance on unseen questions.
- Cite [CITATION.cff](../CITATION.cff). Code is MIT and questions and reference answers are CC BY 4.0.
